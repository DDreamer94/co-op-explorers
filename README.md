# Co-op Explorers — Mountain Workshop

[Play the single-chapter web prototype](https://ddreamer94.github.io/co-op-explorers/?v=workshop-controls-2026-10-16) · [Android ARM64 APK](https://github.com/DDreamer94/co-op-explorers/releases/download/workshop-controls-2026-10-16/co-op-explorers.apk)

Mountain Workshop is the only selectable chapter. Explore a courtyard, machinery hall, high archive, freight tower and upper vault as a 2–4-character crew. A shared brass core provides power and ballast. Reassign roles across linked forward/reverse gears, a supported freight lift, a staffed cargo hoist and a two-gate counterbalance airlock. Recover the core and bring the entire crew into the vault. There is no river or long bridge in this chapter.

Choose Play with AI for one human plus bots, or Online for separate devices. AI fill is an explicit host choice. Android Nearby can host/discover on the same Wi-Fi/hotspot; browsers use Online invites/codes with internet. Every human owns one explorer. Old builds must refresh/update to join.

WASD/arrows move; Shift run; E interact; Space jump; C crouch; F portable sling; T AI stack; R recover only your explorer to the last safe floor, keeping puzzle progress; Esc menu. Touch uses the floating left joystick, round actions and pinch zoom. Floating object labels and overhead character names are hidden. Information shows current gears and archive targets while solving them. Sling horizontal aim follows left/right touch and keyboard input; up/down still adjusts power. Menu distinguishes resume, restart (resets progress), and exit.

The first-time playtest target is 30–45 minutes; actual human duration, puzzle enjoyment and physical-phone testing remain unverified. Known-solution bots execute the route in about 131 seconds. Automated checks cover physical failures, indispensable participation and a full two-human-owned-client/two-bot input-RPC journey. This puzzle-focused build retains the overview camera; first person remains pending. Some later HUD messages still cover part of the supporting crew.

Public multiplayer depends on the temporary beta tunnel and the host Mac remaining online. Android is development-signed. Build checksums and exact scope are in [build-manifest.json](build-manifest.json). This repository contains exported assets, not development source or private runtime state. Godot notices are retained in GODOT_NOTICES.txt.
