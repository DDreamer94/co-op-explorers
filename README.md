# Co-op Explorers — Borrowed Bridge

[Play the one-puzzle web prototype](https://ddreamer94.github.io/co-op-explorers/?v=borrowed-bridge-2026-10-16) · [Android ARM64 APK](https://github.com/DDreamer94/co-op-explorers/releases/download/borrowed-bridge-2026-10-16/co-op-explorers.apk)

Borrowed Bridge is the only playable encounter. Bring the brass core to the exit with the whole 2–4-character crew. The exit key also acts as a counterweight, so using it in one place changes what the others can do. Previous encounters have left the menu and public room catalogue; they are not counted as finished puzzles.

Choose Play with AI for one human plus bots, or Online for separate devices. AI fill is an explicit host choice. Android Nearby can host/discover on the same Wi-Fi/hotspot; browsers use Online invites/codes with internet. Every human owns one explorer. Old builds must refresh/update to join.

WASD/arrows move; Shift run; E interact; Space jump; C crouch; F portable sling; T AI stack; R return to start; Esc menu. Touch uses the floating left joystick, round actions and pinch zoom. Menu distinguishes resume, restart (resets progress), and exit.

This candidate is for feedback before expansion. Automated tests cover 2/3/4-person solutions, required participation, recovery and a full two-human/two-bot network solution. First-time human puzzle completion/enjoyment and physical-phone testing remain pending. This puzzle-focused build retains the overview camera; first person remains future work.

Public multiplayer depends on the temporary beta tunnel and the host Mac remaining online. Android is development-signed. Build checksums and exact scope are in [build-manifest.json](build-manifest.json). This repository contains exported assets, not development source or private runtime state. Godot notices are retained in GODOT_NOTICES.txt.
